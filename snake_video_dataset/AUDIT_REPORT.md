# Video dataset audit before training

The 2026-09-16 interval-sampling audit scanned 62 source videos: 54 rescuer/user-collected and 8 web-collected. Their existing and provisional group metadata yields 61 recording groups. Total duration is 1,836.235 seconds (30 minutes 36.235 seconds), with 51,984 encoded frames. The default 2-second sampler selected 944 frames. One near-black or severely overexposed frame was rejected, 335 within-video near duplicates were removed, and 608 selected JPEGs require manual review. OpenCV reported 10 early-read/frame-count discrepancies; no source video was unreadable.

There are **zero admitted, verified usable frames** in either snake class because no frame review decisions have been supplied. Among frames awaiting review, 191 retain a source-verified Venomous_Snake label, 90 retain a source-verified Non_Venomous_Snake label, and 327 have UNKNOWN labels. Folder or filename hints did not create verified labels. The review index contains every sampled frame's source video ID, frame number, timestamp, label, source, group, split, quality decision, duplicate decision, and review status.

At the video level, 16 sources are provisionally TRAIN, one VALIDATION, one INDEPENDENT_VIDEO_TEST, and 44 remain UNASSIGNED_REVIEW. No group appears in two splits and no two discovered source videos had the same exact file hash. These provisional validation and video-test assignments cover only one venomous video each; they do **not** constitute a meaningful overall video benchmark or a nonvenomous video test. Recording/session relationships beyond the one shared group are not established. Review source provenance and fill `metadata/group_overrides.csv` before using any split for evaluation. The frozen image test set remains the separate official benchmark.

The next experiment should wait for verified frame labels and reliable recording groups. Then create a new, versioned seven-class training candidate from approved snake frames plus the existing non-snake classes, limit each video's contribution to avoid domination, train a **new** checkpoint, and compare per-class results against the existing frozen image test. Assess video performance separately by recording group, with sufficient independent videos in both snake classes. Framewise training treats each selected frame as an image. It can improve appearance robustness across snake movement and camera conditions; MobileNetV3 Large does not learn temporal motion patterns from isolated frames.
